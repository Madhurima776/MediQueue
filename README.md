# MediQueue

MediQueue is a hospital appointment and queue management system.

## Project Structure

- `client/` – React frontend
- `server/` – Node.js + Express backend

## Team Modules

- M1 – Authentication
- M2 – Patient & Appointments
- M3 – Queue Management
- M4 – Doctor & Consultation
- M5 – Receptionist & Check-in
- M6 – Admin & Reports
